# Claude Code へのプロンプト(コピペ用)

---

食券(ミールチケット)生成Webアプリを作ってください。学園祭やイベントの運営者が、ブラウザ上で食券をデザインし、PDFとして出力して紙に印刷、手で切って使うことを想定しています。

## 技術スタック

- Next.js(App Router)+ TypeScript + Tailwind CSS(既存環境)
- PDF生成はクライアントサイドで完結させる。`pdf-lib` + `@pdf-lib/fontkit` を使い、日本語フォント(Noto Sans JP のsubsetまたはwoff→ttf)を埋め込むこと。日本語が文字化けしないことを最優先で確認する
- 状態管理はReactのuseState/useReducerで十分。サーバー・DBは不要。すべてブラウザ内で完結する
- 設定の永続化はlocalStorage + JSONファイルのエクスポート/インポート

## 画面構成

左に設定パネル、右に実寸比プレビュー(1枚目のシート)の2カラムレイアウト。モバイルでは縦積み。

## 機能要件

### 1. 商品(券種)の管理
- 商品を複数登録できる。各商品は以下を持つ:
  - 商品名(例: カレーライス)
  - 値段(例: 500円。「円」表記は自動付与、無料=0円や空欄も許容)
  - テーマカラー(プリセット8色+カラーピッカー)。券の背景帯・枠線に反映され、現場で色による判別ができるようにする
  - イラスト: ①絵文字ピッカーから選択 ②画像アップロード(png/jpg、券内に収まるよう自動リサイズ)③なし、の3択
- 商品の追加・複製・削除・並べ替えができる

### 2. 券のデザイン
- 券1枚のサイズをmm単位で指定(デフォルト: 90mm × 50mm 程度の名刺サイズ)
- 券面レイアウト: 商品名(大)、値段、イラスト、番号(No.XXXX)を配置。凝ったレイアウトエディタは不要で、整ったテンプレート1種でよいが、フォントサイズは商品名の長さに応じて自動縮小すること
- 半券(スタブ)モードのオン/オフ: オンの場合、券が本券+半券に分かれ、両方に同じ番号を印字。境界にミシン目風の破線を入れる

### 3. 通し番号
- 番号の桁数を選択可能(3桁 / 4桁 / 5桁、ゼロ埋め。例: No.0001)
- プレフィックスを自由入力可能(デフォルト "No.")
- 商品ごとに独立した連番を持つ
- **開始番号を指定可能**(追加印刷で前回の続きから刷るため)
- 印刷時に「開始番号〜終了番号」の範囲を指定して出力できる

### 4. シートレイアウト
- 用紙サイズ: A4 / B5 / A3、縦向き/横向き
- 余白(mm)を指定可能(デフォルト10mm。フチなし印刷不可のプリンタ対策)
- 券サイズと用紙サイズから **縦×横に何枚入るかを自動計算** して表示。手動で行数×列数を上書きすることも可能(その場合、券が収まらないなら警告を出す)
- 券と券の間に **切り取りガイド**を入れる。スタイルを選択可能:
  - 破線(券の境界全体)
  - トンボ(交点のみ十字マーク)
  - なし
- 1シートに1商品のみ配置する(混在は不要。商品を切り替えて別シートを出力する運用)

### 5. PDF出力
- 指定した番号範囲の枚数から必要シート数を自動計算し、複数ページのPDFを生成してダウンロード
- 出力前に「商品名 / 番号範囲 / 枚数 / シート数 / 用紙」のサマリを確認ダイアログで表示
- PDF内の寸法は指定mmと正確に一致させること(pt換算: 1mm = 2.8346pt)。「実際のサイズで印刷」すれば券が指定サイズになる旨をUIに注記

### 6. 設定の保存・復元
- 全設定(商品リスト、用紙設定、番号設定)をlocalStorageに自動保存し、再訪時に復元
- JSONファイルとしてエクスポート/インポート(来年のイベントで再利用するため)。アップロード画像はBase64で内包してよいがサイズ警告を出す
- 発行ログ: PDFを出力するたびに「日時 / 商品 / 番号範囲 / 枚数」を記録し、一覧表示。重複印刷の防止に使う。ログのクリアも可能

## 品質要件

- プレビューはPDFと同じレイアウトロジックを共有し、「プレビューと印刷結果が違う」事態を避ける
- 商品名が長い場合、値段が高額な場合(例: 10,000円)でも券面が崩れないこと
- 主要な計算ロジック(自動レイアウト計算、番号範囲→シート数変換)は純粋関数に切り出し、ユニットテストを書く
- UIは日本語。エラー(範囲指定の逆転、券が用紙に入らない等)は具体的なメッセージで案内

## 実装の進め方

1. まず型定義とレイアウト計算・番号計算の純粋関数+テスト
2. 次に設定パネルとプレビュー
3. 最後にPDF生成(日本語フォント埋め込みを最初に動作確認してから券面描画に進む)

完成したら、A4縦・90×50mm・4桁・No.0001〜No.0040(2シート分)のPDFを試験出力して寸法とフォントを確認してください。

## 補足(プロンプト外・あなた向けのメモ)

- **日本語フォント埋め込みが最大のハマりどころ**です。pdf-libは標準フォントに日本語が含まれないため、Noto Sans JPなどのttf/otfをpublic配下に置いてfetch→embed する必要があります。プロンプトにその旨を明記済みですが、Claude Codeが`jsPDF`や`@react-pdf/renderer`を提案してきた場合も、日本語フォント埋め込みの動作確認を最初にやらせるのが安全です
- QRコード照合機能は初版から外しました。必要になったら「各券に `商品ID-番号` を内容とするQRを追加して。qrcodeライブラリでPNG化してPDFに埋め込む」と追加指示すれば拡張できます
- 一気に全部作らせず、上記「実装の進め方」の段階ごとに動作確認しながら進めると手戻りが減ります
